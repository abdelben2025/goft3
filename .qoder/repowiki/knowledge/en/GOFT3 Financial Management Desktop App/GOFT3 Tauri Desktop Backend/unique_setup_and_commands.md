Frontend build is integrated: `tauri.conf.json` sets `beforeDevCommand = npm run dev` and `beforeBuildCommand = npm run build` with `frontendDist = ../dist`, so the Tauri CLI expects a Node.js frontend to be present in the workspace root. The updater endpoint is hardcoded to `https://github.com/abdelben2025/goft3/releases/latest/download/latest.json` with a minisign pubkey embedded in `tauri.conf.json`.
