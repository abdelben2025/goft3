Three sub-folders with a clear dependency direction: `i18n/` is a leaf containing only the Arabic dictionary (`translations.ts`, typed as `Language = 'ar'`). `context/` builds three independent React context providers — `DataContext` (the central state hub wrapping Supabase + Tauri SQLite mirror + localStorage backup, real-time postgres_changes, presence/events, pending-action queue, integrity checks), `LanguageContext` (forces `dir='rtl'`, injects `font-cairo`, exposes a simple `t(key, params)` interpolator over `translations['ar']`), and `ToastContext` (renders `<Toast>` and auto-shows toasts from `recentEvents` in `DataContext`). `hooks/` are pure consumers of these contexts: `useDatabase.ts` wraps `@tanstack/react-query` calls against Supabase for table-level reads; `useDocumentDetails.ts` derives lot/ODS/engagement/payment summaries for a selected piece via `useMemo`; `useNotifications.ts` computes deadline, AE/CP sufficiency, unregistered-document, bordereau, and service-order alerts from the shared `db`. Contexts depend on `services/supabaseClient`, `services/tauriService`, and `types`; hooks depend on contexts but not vice versa. There is no build manifest inside this scope — it is consumed as plain TypeScript/TSX modules.
