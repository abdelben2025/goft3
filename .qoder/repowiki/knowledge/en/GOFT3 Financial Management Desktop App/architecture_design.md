The root is a Vite-driven React app that can be packaged for two runtimes: Electron (`electron.js` main process, `preload.js` bridge, `package.json` build config) and Tauri (`tauri_backend` Rust crate). The renderer mounts `<App />` from `index.tsx`, which wires shared contexts/hooks from `shared_runtime` and routes to page components in `pages`. All data flows through the `services` layer, which chooses between the cloud Supabase client and the local Tauri-backed SQLite adapter; the Rust backend exposes commands consumed by the frontend via `@tauri-apps/api`. Cross-cutting concerns — Arabic i18n, currency/date formatting, password hashing, ODS deadlines, file export/save, update checking — live in `utils` and are imported uniformly by pages and services. A single `package.json` at the workspace root declares both runtime entry points (`main: electron.js`, `scripts.tauri`) and bundles the built `dist/**/*` plus native assets (`icon.ico`, `icon.png`).
