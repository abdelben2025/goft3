Two parallel dev/build flows share one source tree: `npm run dev` / `npm run build` drive the Vite+Electron path (with `electron:start` launching the main process), while `npm run tauri:dev` / `npm run tauri:build` invoke the Tauri CLI against the sibling `tauri_backend` Rust crate. Production Electron installers are produced via `npm run electron:build` (or platform-specific `--win` / `--linux` targets) using the `build` section of `package.json`.
